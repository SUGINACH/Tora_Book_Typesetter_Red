## 4. שורש (`red-build/src/engine/layout/legacy-imud-flow.js`)
בענף `!hFits` של פריט כותרת inline (כ-שורות 1755–1760):
```js
ti -= rollbackTrailingHeadings();
block.fill = 1;            // המשך בטור השמאלי
}                          // ← אין continue: נופלים לדחיפת הכותרת הנוכחית ול-ti++ בהמשך הלולאה
```
לעומת **נתיב הפסקה** (כ-שורה 1913) שאחרי אותו rollback עושה `block.fill = 1; continue;` ⇒ מעבד מחדש מהאינדקס שהוחזר. בנתיב הכותרת: עם `rb ≥ 1` הכותרת הנוכחית נדחפת לטור 2, `ti++` מחזיר את `ti` לכותרת הנוכחית (נפלטת שוב), והכותרת שהוחזרה **מדולגת**. עם `rb = 2` גם הסדר מתהפך.

**השערות שנשללו:** (א) הערות-ענק — בקלט המינימלי אין הערות-ענק; פסקה+h5 בלבד (וריאנט C) משומרת; (ב) חיסרון בספירה (false positive) — המילים נעדרות מהגוף וקיימות רק ב-TOC; (ג) המסלול המודרני — אינו מושפע (מרנדר את שתי הכותרות); (ד) צמד כותרות בכל זוג רמות 3–7 במסמכים קצרים — 25 זוגות, 0 חריגות (הבאג דורש שהצמד ייפול בתחתית הטור הימני).
