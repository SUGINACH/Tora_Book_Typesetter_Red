## 4. סדר מיזוג מחייב

1. PR מנוע: שחזור (strict-xfail) → תיקון → `impact.js` מול baseline v2 → אימות סוכן 4 → CI ירוק על base=`main` → המנהל ממזג.
2. PR תשתית/בדיקות/מסמכים: CI ירוק; ממוזג בסדר הגעה.
3. כששני PRים נוגעים באותו קובץ — מי שממוזג שני מבצע merge של `main` לענף ובונה מחדש חבילות כצעד אחרון; המנהל מתערב רק כשהענף שקט.
4. #38 — לפי D-116/D-119. #60 — כשייצא מטיוטה.
