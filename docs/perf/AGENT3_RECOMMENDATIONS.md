3. **ייצוא PDF עובד רק ל-315 מתוך 1,721 המשפחות (18%)** [ריצה, PR #53]: 100 משפחות TTF הן CFF בסיומת `.ttf` (מפצל הגופנים תומך ב-TrueType בלבד), 16 נכשלות בפיצול, וכל 1,289 ה-WOFF2 נדחים. 12 גופני ברירת המחדל כולם מייצאים. זו הבעיה התפקודית הגדולה בנתיב הגופנים — **להחליט על עדיפות** מול P6/P7.

5. **רישוי — להזמין בחינה** [ריצה, אינדיקטיבי, PR #53]: רק 13.8% מהקבצים נושאים טקסט רישיון חופשי מזוהה; 25 קבצים נושאים סימון רישיון-ללקוח; 5 מתוך 12 גופני ברירת המחדל עם `fsType`=6. לא בוצע דבר.
6. **להפנות לסוכן 1** את אוספי העיצוב בעלייה (62% מהבתים הדחוסים), **ולא להשקיע בביצועי מנוע או ייצוא PDF** — אין שם בעיה.

## 3. מדיניות WOFF2 — האפשרויות (מעודכן לקטלוג המלא)

**הבעיה [ריצה]:** משפחה מורחבת (WOFF2) מוצגת בגופן האמיתי אך נמדדת בטבלה — העימוד אינו תואם את התצוגה — וייצוא ה-PDF שלה נכשל.

**מבנה הקטלוג [ריצה, סריקת כל 1,315 הקבצים — PR #53]:** מתוך 1,289 משפחות ה-WOFF2-בלבד: **864 עברית + TrueType** (67%), **277 עברית + CFF** (21%), **148 בלי אותיות עבריות** (11.5%). (מדגם ה-24 ב-`WOFF2_EVIDENCE.md` העריך 29% בלי עברית ו-25% CFF — תוקן שם.)

**מה נמדד אחרי המרה ל-sfnt** (מדגם מדורג של 24; קורפוס אחד, הגדרות ברירת מחדל): נפח ×2.00; `parseFont` מקבל 24/24; 15/24 מקבלים עימוד שונה — מספר השורות בין **−37% ל-+15%** מול הטבלה; ייצוא PDF 16/24 (CFF — 0/6).

## 4. מדידה על GitHub Pages (תנאי סוכן 5 ל-#38) — ערכה

כל מספרי הדפדפן שלי הם הדמיה (אין לסביבת הסוכן גישה ל-`github.io`). **שלב 1 — "לפני" על Pages האמיתי** (כרום; קרה: DevTools ← Network ← Disable cache + רענון קשיח, המתן ~10 שניות; חמה: רענון רגיל), הדבק בקונסול והחזר לי את שורת ה-JSON:

```js
(() => {
  const e = performance.getEntriesByType('resource');
  const cat = (u) => /app\.bundle\.js|engine-worker\.bundle\.js/.test(u) ? 'bundle' : /imud-fonts\.json|fonts-extended\.json/.test(u) ? 'catalog'
    : /(shaar_|ornaments_|section_dividers|header_ornaments)[^/]*\.json/.test(u) ? 'design' : /\/fonts\//.test(u) ? 'font' : 'other';
  const by = {}; for (const r of e) (by[cat(r.name)] = by[cat(r.name)] || []).push(r);
  const end = (c) => by[c] ? Math.round(Math.max(...by[c].map((r) => r.responseEnd))) : null;
  const kb = (c) => by[c] ? Math.round(by[c].reduce((s, r) => s + (r.transferSize || r.encodedBodySize || 0), 0) / 1024) : 0;
  const nav = performance.getEntriesByType('navigation')[0];
  const fcp = (performance.getEntriesByType('paint').find((p) => p.name === 'first-contentful-paint') || {}).startTime;
  console.log(JSON.stringify({ host: location.host, requests: e.length, bundleDone: end('bundle'), catalogDone: end('catalog'), fontFilesDone: end('font'),
    designsDone: end('design'), lastResponse: Math.round(Math.max(...e.map((r) => r.responseEnd))), fcp: Math.round(fcp), load: Math.round(nav.loadEventEnd),
    fontsInDocument: document.fonts.size, KB: { bundle: kb('bundle'), catalog: kb('catalog'), design: kb('design'), font: kb('font') } }));
})();
```

`fontFilesDone` הוא הקירוב ל"גופנים מוכנים" שבהדמיה, ו-`fontsInDocument` אמור להיות 11. אשווה לדגם: אם בתים וסדר אבני הדרך תואמים — ההדמיה מכוילת וה"אחרי" שלה אמין יותר; אם לא — אעדכן את הדגם ואדווח.
**שלב 2 — "אחרי":** (א) למזג את #38 ולמדוד שוב (החזרה לאחור = הסרת שורת `<script>` אחת); או (ב) בלי מיזוג — DevTools ← Sources ← Overrides, ליצור את `font-prefetch.js` ולהוסיף את שורת ה-`<script>` ל-`index.html` מקומית (**[לא נבדק]** ע"י). (ב) מסורבל יותר; (א) בטוח מספיק לדעתי, וההחלטה שלך.

## 5. מה מומלץ לא לעשות (ולמה)

- **כפתור "טען פונטים נוספים":** כל 1,721 המשפחות כבר לבחירה וכל אחת נטענת בבחירתה; טעינה גורפת ≈ 115MB.
- **להעביר WOFF2 ל-parser כפי שהוא, או "לתקן" בנפילה שקטה:** נדחה (`bad-sfnt-version`); נפילה שקטה היא בדיוק מקור אי-ההתאמה בין מדידה לתצוגה.
- **`<link rel=prefetch|preload>` לגופנים ב-HTML:** מאחר את FCP ב-≈90% [הדמיה].
- **להתחיל שליפת גופנים בתחילת המסמך (לפני ה-bundle):** FCP +88% [הדמיה]. הנכון — מיד אחרי טעינת ה-bundle (זה מה ש-#38 עושה).
- **להמיר גופנים לפני בחינת רישוי:** המרה היא העתקה/הפצה נוספת של הקבצים.

## 8. מגבלות הראיות

- **כל מספרי הדפדפן הם הדמיה:** HeadlessChrome 153, vCPU יחיד, 4GB, שרת מקומי (HTTP/2, gzip לטקסט בלבד — גופנים ללא דחיסה, שמרני; RTT ורוחב פס משותף). מדדים תלויי-CPU מנופחים לעומת מחשב רגיל. Pages לא נמדד [לא נבדק].
- **המרת WOFF2:** מדגם של 24 (נפח, עימוד, ייצוא); קורפוס אחד והגדרות ברירת מחדל. כיסוי עברית וסוג קווי המתאר נסרקו על **כל** הקטלוג.
- **רישוי:** סיווג אינדיקטיבי לפי מטא-דאטה בתוך הגופן — אינו חוות דעת משפטית; היעדר רישיון מזוהה אינו הוכחה לאי-חופשיות, ונוכחות רישיון אינה הוכחה לתוקפו. `fsType` מדווח כפי שהוא; פרשנות הצירוף 6 לא אומתה מול נוסח המפרט.
- **"גופנים בשימוש מוכח":** 20 משפחות מ-9 מקורות הגדרות בריפו; אין הגדרות של ספרים אמיתיים.
- **CI ירוק** מראה שלא נשבר דבר; הוא אינו מאמת את ממצאי הדוחות.
