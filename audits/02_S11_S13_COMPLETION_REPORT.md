## S11 — הרחבות: סגנונות מותאמים, DOCX, המלצות עריכה

### מה נבנה
- **חוזה סגנונות מותאמים (REQ-PAR-06):** טריגרים (linePrefix / pattern / inlineMarker «…» **וגם מפרידים סימטריים ~…~** / קומבינטורים AND/OR), שישה מצבי פריסה (regular / full-width עם פס+מונה+עיטור מקושר / side-note / footnote / endnote / new-location), מונים (hebrew-geresh עם איפוס per-part), סכמת אימות עם **שגיאות עברית מאובחנות** (קוד+נתיב+מזהה+משפט מלא).
- **התאמה לפני המדידה** (דפוס D-42 — השורש הסיבתי): הסגנון נקבע לפני שבירת השורות; טווחי inline נמדדים בגודל הסגנון (ה־hash מושפע בפועל, לא רק הצבע).
- **ייבוא DOCX עצמאי (REQ-PAR-07):** קורא ZIP עצמאי (STORE+DEFLATE; המנפח הטהור ≡ zlib ביט־לביט — מוכח), XML עם מגננים, Heading1–7→כותרת N, **הערות וורד→הערות־סוגריים במקום ההפניה** (וממשיכות למרזב המנוע), דחיית פורמט בעברית בלי קריסה (חוק 14).
- **המלצות עריכה מוכחות (REQ-GOV-11, D-16):** כשהמנוע מיצה אפשרויות — הצעות שמירות־תוכן עם **הוכחת reflow חיה**: הפעלה מחדש של המנוע מוכיחה הסרת הממצא + אפס ממצאים חדשים + שינוי hash; בלי הוכחה ⇒ rejected ולעולם לא מוצג. החלה מה־UI מחזירה בדיוק את ה־hash המוכח (מקור יחיד `applyEdit`).
- **חבילת הרחבות (§8.3):** ‏`tora-typesetter-extensions` v1 — ייצוא דטרמיניסטי, ייבוא all-or-nothing, תקציר שיתוף קריא בעברית.

### תיקוני שורש שנתגלו בסגירת השער
1. **בדיקת עומק שגויה ב־collectFootnoteText** (w:r בעומק d0+2, לא d0+1) — **כל הערות הוורד הושמטו בשקט**; הוסרה.
2. **before-shaar-main נדחה בשקט ללא ערכת נושא** — "עמוד לוגו לפני הפתיחה" לא הוצב; העיגון המבני הקבוע הוא ראש המסמך.
3. **חשבונאות סמנים בזרימות footnote/endnote מותאמות** — הסמן לא נספר במקור ⇒ contentPreserved=false עתידי; הסמן מוקצה/מתויג כמו note-ref (D-30/D-53).

## S12 — ייצוא מושלם + שכבת מדידה מתמטית

### מה נבנה
- **שכבת מדידה מתמטית (REQ-LB-01 מימוש B, D-18 → D-72):** פרנסר טבלאות גופן **עצמאי לחלוטין** — sfnt/head/hhea/hmtx/maxp/cmap (fmt4+fmt12)/kern fmt0/GPOS PairPos fmt1/OS/2 — ‏**במקום הבאת HarfBuzz-WASM/fontkit החיצוניים** (דוקטרינת אפס־התלות של הריפו; אותה מטרה, אפס תלות זרה). מאחורי דגל `measure-impl`; ברירת המחדל נשארת table (רציפות hash מ־S1). **הוכחות:** פרנסר מאומת מול אורקל צולב (fontTools) על גופן אמיתי — כל ערכי האמת זהים (כולל sCapHeight@88 שאומת על גופן v4 אמיתי); ‏parity A↔B ≤0.01px על מילות הקורפוס; **שקילות שבירות מלאה: 589 שורות, 0 הבדלים** (artifact).
- **מקור גיאומטריה יחיד (REQ-EXP-01):** `geometry-projector` מקרין את מודל CP5 למלבנים מפורשים — הרינדור החי, ה־PDF וה־HTML מקרינים מאותו מקור (**הורג את מחלקת live≠export של כל הגרסאות הקודמות**).
- **כותב PDF טהור (REQ-EXP-03):** PDF 1.4 בכתיבה ידנית — ‏CIDFontType2 עם **תת־גופן TrueType מוטמע** (FontFile2; מצומצם לגליפי המסמך — ‏**89% חיסכון**) + ‏ToUnicode (**חילוץ טקסט עברי מדויק — אומת מול pdftotext: מולטיסט תווים זהה**); ‏עץ סימניות (H1/H2, כותרות UTF-16BE); ‏קישורי TOC לחיצים (GoTo); ‏סימני חיתוך + ‏Trim/BleedBox מרישום גדלי העמוד; ‏RTL ויזואלי תקין.
- **HTML עצמאי (REQ-EXP-02):** חד־קובץ, dir=rtl, כללי @page מהרישום, אפס הפניות חיצוניות (offline-guard עם exit 7), **כל עמוד זהה בתים לרינדור החי**.
- **ZIP פרויקט (REQ-EXP-04):** מסמך+הגדרות (מיגרציה v1→v2)+הרחבות+ערכה — ‏JSON מובנה (אפס תבניות מחרוזות), roundtrip מלא.
- **פריט דחוי S3 נסגר:** cap-height של המילה הראשונה ממדדי אמת (OS/2 sCapHeight; נפילה מתועדת).

### תיקוני שורש שנתגלו בסגירת השער
1. **מלאי הגופן נבנה מטקסט המקור** — גרשיים **נגזרים** (גיליון "כ״ב", תוויות TOC) הושמטו בשקט ⇒ אובדן תוכן בייצוא; כעת המלאי מכל הטקסט המצויר בפועל.
2. כותרות סימניות כ־UTF-16BE (חוזה PDF §3.8.4) — היו גרבליות בלטינית.
3. מערך W בצורה 1 התקנית (עם סוגריים).
4. בסיס שורה לפי מודל תיבת־שורה של CSS (half-leading + ascent מהגופן) — היה 0.78em מלמטה (היסט ~15px).
5. הפרדת חבילות (D-65) נשמרה: סמן `/* node-only */` בבאנדלר — חבילת האפליקציה נשארת בלי המנוע (43 מודולים).

### אימות חיצוני (כלים אמיתיים, לא רק עצמי)
- **fontTools** פותח את תת־הגופן הנבנה — רוחבים וקווי־מתאר זהים למקור.
- **pdfinfo** — מספר עמודים זהה למנוע.
- **pdftotext** — חילוץ העברית שלם ומדויק.
- **pdftoppm (רסטר)** — ‏parity גיאומטרי: bbox דיו ≤6px בדגימה (סביבות גליף מתועדות); **פסי שורות מיושרים למודל בדיוק של 1–2px**.
